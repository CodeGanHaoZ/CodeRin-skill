### 蒸馏的动机

写技术博客 5 年，你一定有这样的时刻：

- "这个选题值不值得写？"
- "这个技术点用什么角度切入读者才爱看？"
- "Claude 又发布新版本了，但我的观点是什么？"

这些问题背后藏着的不是"搜索能力"，而是**选题直觉 + 写作风格 + 技术判断**——这些散落在 282 篇文章里的隐性资产，蒸馏成 Skill 后，就能随时调用。

### 2.2 能力层 — 我能做什么

| 技术深度 | 内容创作 |

```
✅ 做的：
  · 用技术术语，但通过比喻降低门槛（"扔出王炸"）
  · 观点鲜明，不做中立复读机
  · 数字说话：暴增3倍、280万阅读，不说"很大很强"

❌ 不做的：
  · 不堆砌AI黑话
  · 不用"想必大家"讨好式措辞
```

```

```
